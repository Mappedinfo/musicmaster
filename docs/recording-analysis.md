# 录音复盘：从片段到练习

录音复盘用于找出一份演唱中值得重练的片段。它先展示声音里的可测变化，再给出可能的声乐原因、替代解释和验证练习。所有判断都绑定时间区间，便于回听。

## 准备与使用

实时跟唱提供文字教练：每次显示一个当前建议，采用持续证据与迟滞，减少提示跳变。它描述音高、检测质量和强度变化，具体的声乐原因由唱完后的完整复盘分析。

实时跟唱默认开启“录音与自动复盘”。歌曲播放结束或点击“结束并复盘”后，连续采集的麦克风音频会保存到当前浏览器并生成报告；完成后自动进入录音复盘。暂停期间不录入音频，续唱保留同一次演唱；重唱或切换歌曲会先保存已有录音。每次录音最多 20 分钟。本地录音区提供查看、下载、重试和删除，刷新后可恢复已保存的录音。采用外放模式时标记为混合声源，检测和原因推断受到限制。

带伴奏录音先用本机 Demucs 工具分离。网页选择干声或已经分离的人声，点击“开始分析”；也可导入本地工具生成的 JSON 报告。分析过程无需麦克风权限。原唱人声可作为独立参考，伴奏用于确认版本和时间位置。

网页的“我的演唱”与“参考人声”是两个独立输入。同一份演唱不能同时充当自己的评分参考。参考偏移和转调在输入区调整；只有对齐可信、公共片段足够且音高可用时，才显示定量比较。不同编曲、未对齐的参考和检测失败都会显示具体原因。

网页默认搜索固定偏移，以声部节奏、局部音程和音高轮廓生成候选，提供三处成对试听；候选仍需回听共同乐句确认，估计不成功时不评分。本地混音工具另外核验分离伴奏的包络与多窗口波形内容，强弱节奏相似本身不能证明同源。两条流程均不按总时长拉伸，也不自动纠正你的局部抢拍／拖拍。

优先问题包含时间区间、观察依据和练习动作，点击即可定位或循环试听。报告没有附带音频时仍能查看；选择对应的本地音频并核对文件身份后可回听。切换模式或页面会暂停试听，保留当前页面内的文件、位置和结果。

## 分析与自动推断

共享 JS 内核计算音高、电平、静音分句与独立的持续音区间。音域采用分位数；持续音分析避开起音、收音和明显音符变化。自然旋律变化、滑音和有规律的颤音不能仅凭整曲标准差被判为不稳定。

持续音允许最多 60ms 的短检出缺口，但有效时长只统计真实有声帧，覆盖须达到 80%。有缺口而未评估周期性时，不把残差波动解释为不稳或挤嗓。音程比较要求两边存在同一句内对应的相邻持续平台，至少三组才输出；缺少这些条件时字段为空。

自动推断使用可解释的规则，并把观察与假设分开：

- **气息分配可能不足**：多个持续音出现强度下降与音高下滑时，提示检查句尾的气息分配。主动渐弱和收音方式也可能产生相同现象。
- **可能用力偏重／挤压发声**：同一文件内出现多项异常变化时，给出低可信假设，并安排降低音量的同元音对照。单纯高音、响亮或明亮不能证明挤嗓。
- **可能偏气声／闭合不足**：组合观察谐波与谱形变化，并安排同音高、同元音的干声对照。分离音频的谱形受到模型影响，推断可信度相应降低。

这里的可信度是证据强弱标签，未经临床或教学人群校准，不是病因概率。原始 H1−H2 未做声道共振峰校正，也不是声门闭合程度的直接测量。没有足够证据时，报告解释缺少的条件并建议补录对照，不把“未检出”写成“没有问题”。

相关研究发现，H1−H2 与气声有关，但受声道形状影响，其关系可能非单调；它对挤压发声的区分也随性别、元音和声强改变。具体依据见 [Samlan 与 Story 的声源模型研究](https://pubmed.ncbi.nlm.nih.gov/21498582/)、[Toles 等人的发声条件比较](https://pubmed.ncbi.nlm.nih.gov/40021420/) 和[声强／元音对倒谱分析的影响](https://pubmed.ncbi.nlm.nih.gov/22480754/)。这些研究没有直接验证带伴奏、经人声分离后的歌曲录音，因此当前自动推断仍需回听与对照练习验证。

## 数据与发布边界

手动导入通过 File、Blob 和 Worker 在本机内存中处理；实时跟唱开启自动录音后，录音、参考素材与报告保存到当前浏览器 IndexedDB。两种流程均不上传音频或报告。下载由用户触发，清除网站数据会删除本地记录；存储失败时录音只留在当前页面，应先下载备份。正在演唱而尚未结束的录音还未持久保存。

命令行的私人音频、参考素材、模型和报告留在 `stems/` 下，该目录整体被 Git 忽略。不要把私人结果放进 `public/` 或文档截图。GitHub Pages 只发布通用网页；本机分离工具的用法见 [本地分析工具说明](../tools/vocal-analysis/README.md)。
